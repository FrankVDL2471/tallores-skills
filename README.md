# tallores-skills

Claude skills for building and integrating restaurant websites with the TalloRes reservation system.

---

## What are Claude Skills?

Skills are instruction files that teach Claude how to handle specific tasks. When you add a skill to a Claude Project, Claude will automatically follow its workflow whenever a matching request comes up — no need to re-explain the process every time.

---

## Skills in this repo

### `tallores-website`

Scaffolds a complete restaurant website from scratch. Given basic details about your restaurant (name, address, style), Claude will generate a ready-to-run single-page site with a hero section, menu, contact info, and reservation integration.

**Triggers:** "set up a restaurant website", "create a restaurant site", "build a website for my restaurant"

**What it produces:**
- `index.html` — single-page site with Home, Contact, Menu (optional), and Reservation sections
- `brand_assets/theme.json` — design tokens (colors, fonts, spacing)
- `brand_assets/content.json` — all text content and asset paths
- `CLAUDE.md` — project context file for future Claude sessions
- `serve.mjs` — lightweight local dev server (Node.js, no dependencies)

**Requires:** a TalloRes RestaurantId (see below), and optionally a logo, photos, and a menu PDF

---

### `tallores-integration`

Integrates the [TalloRes](https://tallores.com) online reservation system into any existing website. Supports floating widget, direct reservation links, and embedded iframe — Claude will pick the right method based on your site's structure.

**Triggers:** "add a reservation widget", "integrate TalloRes", "add online reservations", "booking button"

**What it does:**
- Asks for your TalloRes RestaurantId
- Stores it in the appropriate config location for your stack (static HTML, React, Next.js, WordPress, etc.)
- Adds the floating widget script before `</body>`
- Updates reservation links or embeds an iframe for a dedicated reservations page

## Installation

Skills are used inside **Claude Projects** on [claude.ai](https://claude.ai).

### Step 1 — Create or open a Project

Go to [claude.ai](https://claude.ai) → **Projects** → create a new project or open an existing one.

### Step 2 — Add the skill

1. Open the project's **Instructions** panel
2. Copy the full contents of the skill's `SKILL.md` file
3. Paste it into the instructions field
4. Save

Repeat for each skill you want to include. You can combine both skills in the same project — `tallores-website` already depends on `tallores-integration`.

### Step 3 — Start using it

Just describe what you want in the chat:

> "Set up a website for my Italian restaurant called La Stella"

Claude will follow the skill's workflow automatically.

## Requirements

- A [Claude.ai](https://claude.ai) account with Projects access (Pro, Team, or Enterprise)
- A [TalloRes](https://tallores.com) account with a RestaurantId (find it at [app.tallores.com/nl/settings/reservation-widget](https://app.tallores.com/nl/settings/reservation-widget))
- Node.js (only needed to run the local dev server generated by `tallores-website`)
